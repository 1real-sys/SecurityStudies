# Introdução

Boas-vindas ao módulo de desofuscação de JavaScript (JavaScript Deobfuscation)!

A desofuscação de código é uma habilidade importante para quem deseja se tornar competente em análise de código e engenharia reversa. Durante exercícios de red team e blue team, frequentemente encontramos código ofuscado que busca ocultar determinadas funcionalidades, como um malware que utiliza código JavaScript ofuscado para obter seu payload principal. Sem compreender o que esse código está fazendo, talvez não saibamos exatamente qual é seu comportamento e, consequentemente, podemos não conseguir concluir o exercício de red team ou blue team.

Neste módulo, começaremos aprendendo a estrutura geral de uma página HTML e, em seguida, localizaremos o código JavaScript presente nela. Depois disso, aprenderemos o que é ofuscação, como ela é realizada e onde é utilizada. Na sequência, aprenderemos a desofuscar esse código. Quando o código estiver desofuscado, tentaremos compreender seu uso geral para reproduzir sua funcionalidade e descobrir manualmente o que ele faz.

Os seguintes tópicos serão abordados:

- Localização de código JavaScript
- Introdução à ofuscação de código (Code Obfuscation)
- Como desofuscar código JavaScript
- Como decodificar mensagens codificadas
- Análise básica de código
- Envio de requisições HTTP básicas
